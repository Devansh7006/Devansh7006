## About me

I’m **Devansh Goyal**, a cybersecurity researcher and security tool developer interested in how systems behave, where they fail, and how to make them more resilient. I work across defensive detection, offensive security, digital forensics, and automation—with a particular interest in low-level systems and practical security tooling.

## What I work on

| Focus area | Interests |
|---|---|
| **Threat detection** | Endpoint telemetry, behavioral analysis, detection engineering, and threat-surface mapping |
| **Offensive security** | Web and network testing, vulnerability research, binary analysis, and security auditing |
| **Email & identity security** | SPF, DKIM, DMARC, phishing prevention, and digital forensics |
| **Security engineering** | Low-level tooling, automation, custom scripts, and telemetry workflows |
